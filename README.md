📁 File Organizer

- A simple browser-based file organizer that helps users upload, categorize, preview, and rename files for better local organization.

✨ Features

- Upload multiple files directly in the browser

- Automatically organize files by type (images, documents, etc.)

- Rename files easily

- Preview supported file formats

- Store file metadata locally for quick access

- Clean and minimal user interface

🚀 How It Works

- Upload files using the file input

- Files are grouped automatically based on their type

- Rename files or preview supported formats

- Metadata is saved locally so files stay organized during the session

📂 Use Case

- This project is designed to practice:

- DOM manipulation

- File handling in JavaScript

- Clean UI structure

- Working with local storage

📌 Notes

- All processing happens in the browser
